# Lab Analytics Projekt

Dieses Projekt bündelt jegliche Analyse und Visualisierungsskripte die ich im Rahmen meiner Masterarbeit am FZJ brauche, darunter:
  
  - `afmmetrics`: Ein Modul zur Analyse von AFM Bildern, isnbesondere von Aufnahmen von μGelen.
  - `ecanalytics`: Ein Modul zur Analyse, Fitting, Validierung und Visualisierung von EIS Daten.
